# 🚀 WiFi Router User Traffic Controller

Take full control of your WiFi network with this powerful Python-based router traffic manager! 🛜💻

## 🔥 Features

✅ **Remove Users** – Instantly kick unwanted devices off your network. No freeloaders allowed! 🚫📡  
✅ **Log User Data** – Keep track of who’s using your WiFi, their IP addresses, and connection times. 📝👀  
✅ **Add Users** – Grant access to trusted devices with a simple command. 🔓📶  
✅ **Control Bandwidth** – Set upload & download speed limits for all users, ensuring fair usage. 📊⚡  
✅ **Whitelist Users** – Allow VIP users to enjoy unrestricted speeds. No slowdowns for priority devices! 🌟🚀  

## 🛠️ Installation

1. Clone this repository:
   ```sh
   git clone [https://github.com/yourusername/wifi-router-control.git](https://github.com/MoranLeven/RouterControl.git)
   cd RouterControl
   ```
   
2. Run the program:
   ```sh
   python test.py
   ```
